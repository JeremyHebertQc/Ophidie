# Ophidie

Bienvenue sur le dépôt de Ophidie. Ophidie est un Snake créé dans le cadre du cours de programmation orientée objet du Cégep de Sherbrooke. / Welcome to the Ophidie repository. Ophidie is a Snake created as part of the object-oriented programming course at Cégep de Sherbrooke.
*** 
## Exigences minimales
- [X] Présence d’au moins un menu avec options permettant de jouer et de rejouer en revenant au menu après la partie.
- [X] Présence d’une fenêtre d’instructions pour savoir comment jouer.
- [X] Présence d’une fenêtre de statistiques du jeu (par exemple, meilleurs scores, moyenne des scores, temps de jeu, nombre de parties disputées, nombre de niveaux franchis, etc.)
- [X] Présence de sons et, optionnellement, d’une musique tout au long du jeu.
- [ ] Enregistrement dans un fichier des informations relatives au jeu (par exemple, les statistiques du jeu, l’état de la partie (sauvegardes effectuées durant le jeu s’il y a lieu), paramètres modifiés par le joueur, etc.)
